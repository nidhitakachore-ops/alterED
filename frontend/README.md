# alterED — Academic Portal

Static front-end project for the alterED academic portal.

## Open in VS Code
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html` with Live Server (recommended) or use a local static server.
4. `style.css` contains the shared UI styling and `script.js` contains navigation, role access, login/logout and UI behavior.

## Demo roles
- Student: student portal and student-only pages.
- Faculty: faculty portal access; Admin navigation is hidden.
- Admin: administrative access plus all role navigation.

The project is front-end/demo logic only; login credentials are not connected to a real backend.
